- Beautiful medieval/roses aesthetic

- Secondary links + social icons (Instagram & TikTok placeholders)

---

## Enable GitHub Pages

1. Go to the repo → **Settings** → **Pages** (left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Branch: `main` → folder: `/ (root)`
4. Click **Save**

After ~1 minute the page will be live at:

**https://dunedawes.github.io/via/**

---

## Customize

Open `index.html` and replace these placeholders:

| Placeholder | What to put |
|-------------|-------------|
| `#REPLACE-WITH-YOUR-CHECKOUT-LINK` | Real $35 payment link (Gumroad / Stripe / etc.) |
| `#REPLACE-INSTAGRAM` | Instagram profile URL |
| `#REPLACE-TIKTOK` | TikTok (or delete the icon) |
| `#REPLACE-OPTIONAL-LINK` | Free guide or any other link |

You can also change the avatar letter “V”, bio text, or button titles.
